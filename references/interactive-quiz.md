# 可选模块：离线交互刷题

仅在用户要求网页刷题、交互自测、HTML 题库或明确选择 `interactive_quiz` 时启用。支持课程定义、问答、计算题和面试口述训练；不替代知识讲解。用户只要界面或模板时，使用中性示例，不抽取个人经历。

## 生成入口

从 [示例题库](../examples/interactive-quiz.json) 开始，接口见 [Schema](../assets/interactive-quiz.schema.json)。配置与成品保存到技能仓库外。

```text
python scripts/build_quiz.py --config path/to/quiz.json --check-only
python scripts/build_quiz.py --config path/to/quiz.json --output path/to/刷题.html
```

默认拒绝覆盖；只有本次确实要求更新且已保留用户修改时才传 `--overwrite`。生成器只用 Python 标准库；成品无需联网、服务端、CDN 或额外安装，可双击使用。模板为 [quiz.html](../assets/quiz.html)。

交付必须只有一个自包含 `.html`：题库、CSS、JavaScript及需要的图像/字体/公式资源都内嵌，不能依赖相邻文件、网络请求或 CDN。JSON仅用于内部生成，不作为必需附带文件。若需数学渲染，也必须把渲染器完整内嵌或在生成时转换为内联 SVG/MathML。进度备份是读者主动导出的可选数据，不是运行依赖。

## 内容与数据

- `bank_id` 是该题库稳定的身份，同一题库修订保持不变；不同课程或私人题库使用不同值。
- 每题有稳定 `id`、`category`、`question`、`answer`，可附 `criteria` 作答要点数组。改顺序不改 ID；题目、答案或评分要点变化后旧自评自动失效。不要用数组下标标识题目。
- 可选 `title` 是简短题名，与正常字重的题干分开显示；不填写时直接显示题干，不擅自截取第一行当标题。标题变化也使该题旧自评失效；不带标题的旧配置保持原进度指纹兼容。
- 可选 `learning` 对象按实际需要提供 `concept`（核心概念）、`method`（动笔顺序）、`explanation`（知识与推导）、`example`（完整示例）、`pitfalls`（易错提醒）。仅显示已提供的部分，默认折叠；没有教学字段时不生成空帮助面板。各值为非空纯文本，不接受原始 HTML。
- 题干、答案和要点均为纯文本，支持换行及 Unicode 符号；HTML 字符显示为文字。当前模板不渲染 LaTeX/Markdown，复杂矩阵可用多行等宽文本。需要排版公式时另配离线数学渲染并单独验收，不能把原始 TeX 当作已排版成品。
- 内容按来源核验，预测题与官方题区分；面试经历和项目指标遵守隐私与证据契约，不把演示题包装成真题。配置中的答案本来就包含在 HTML 中，本地隐藏只是练习交互，不是答案保密措施。

## 交互约定

### 默认界面

- 界面文字统一用 `system-ui, sans-serif`，标题、题干、按钮和输入框继承系统字体；不用宋体、Times New Roman 或装饰性英文字体。数学公式可使用浏览器数学字体以保证分式、矩阵和上下标结构，公式中的自然语言仍可继承系统字体。这不改变 Word 字体规范。
- 先显示题名与题干，题干不整段加粗；下面依次为可选学习帮助、作答草稿、揭晓答案和自评。学习帮助分为核心概念、讲解与例题、易错提醒，按需展开。内容顺序按先修关系设计时，保持稳定题目ID；UI自身不自动推断课程难度或保证学习效果。
- 桌面使用左侧设置与右侧题卡，窄屏使用单列且默认收起设置；题号导航独立折叠。统一字号、按钮和间距，不用密集的英文装饰标签。学习帮助与导航不遮挡题目或长答案，底部按钮不浮盖正文。
- 继续只交付一个离线HTML，不下载或引用外部字体。自定义公式等宽内容放进可横向滚动的局部容器，不让整个页面横向溢出。只有用户明确要求时才改变这些默认设计。

保留分类、顺序/随机、先作答后揭晓、自评、上一题/下一题、进度保存。支持筛选未评题、需复习题及自评通过题，并可进入错题重练。完成页分别显示已评、未评、待复习，不把“翻过题目”算作答对。

先在输入区写出答案或口述，再揭晓参考答案与评分要点，选择“需复习 / 基本会 / 自评通过”。再次进入一题仍隐藏答案，已通过题可重测。统计明确称为自评，不能把一次点击写成客观正确率或已掌握。没有自动评分、语音识别、间隔复习算法或跨设备同步时，不声称具备。

浏览器仅持久保存自评进度；作答草稿只在当前页面内存中保留，切题不丢、刷新清空。手机默认收起设置，优先显示题目；支持题干搜索、题号跳转和收起答案。本轮统计只计本轮自评，历史通过记录不充当本轮作答。支持 JSON 导出/导入进度；导入校验题库身份、版本和题目内容，仅恢复仍匹配的记录。存储不可用时显示提示并继续临时练习。使用新版 HTML 的相同 `bank_id` 可以迁移进度，但浏览器对本地文件的存储隔离可能不同，搬文件前建议导出。

## 验收

核对题数、类别和题目 ID，执行正常生成、拒绝覆盖、重复 ID、恶意文本、空题库等检查。运行实际 JS，验证分类/随机/筛选、重测隐藏答案、未评不算通过、错题重练、进度恢复和异常导入。验证有、无教学字段时帮助面板的显示、折叠与切题重置，教学文本中的HTML保持文字；旧配置与进度继续可用。生成后用浏览器检查桌面、手机横屏、常见竖屏和窄屏，核对系统字体、长题名与长答案、局部公式滚动、页面溢出和按钮可达性；若仅运行脚本或 DOM 测试，交付时说明未完成真实浏览器视觉验收。只交付用户要求的 HTML（用户要求才附题库 JSON），保留原始来源在内部。
